# ConsoleGraphicsEditor
## Опис
ConsoleGraphicsEditor - графічний редактор в консолі, який генерує графічні моделі, з якими користувач може взаємодіяти тим чи іншим способом. Створений виключено в навчальних цілях.

### Можливості
- створення моделі з властивостями: назва, опис, тип, колір, символ, координати, розміри, ціна;
- перегляд усіх моделей у вигляді таблиці;
- пошук за двома характеристиками одночасно;
- видалення за номером або за характеристикою;
- демонстрація поведінки моделі: переміщення, зміна розміру й кольору, перемикання видимості, обчислення площі, виведення інформації;
- демонстрація глобальної поведінки моделей - зміна масштабу, а також виведення їх кількості;
- перевірка введення: некоректні дані запитуються повторно, програма не завершується.

## Відомі обмеження
- Програма керує властивостями моделей, але не відмальовує їх на полотні.

## Запуск
Готова збірка є. Достатньо файлу ConsoleGraphicEditor.exe для запуску програмного додатку.

1. Завантажити проєкт: на сторінці репозиторію GitHub натиснути **Code → Download ZIP** і розпакувати архів (або клонувати репозиторій через **Git → Clone Repository** у Visual Studio, якщо необхідно працювати з програмним кодом).
2. У розпакованому архіві відкрити .exe файл, що можна знайти за шляхом ".../ConsoleGraphicEditor/bin/Debug/net10.0/ConsoleGraphicModel.exe", для запуску програмного застосунку.

## Використання програмного забезпечення

На старті задаються (усі значення в межах 1–1000):
- максимальна кількість об'єктів
- максимальні розміри полотна.

Після введення значень виводиться таке головне меню:
- 1 — додати;
- 2 — переглянути;
- 3 — знайти;
- 4 — продемонструвати поведінку;
- 5 — видалити;
- 6 — продемонструвати поведінку статичних методів;
- 0 — вийти.

### Створення об'єкта

Обмеження при створенні об'єкта (W, H — ширина й висота полотна):

| Поле | Допустиме значення |
|------|--------------------|
| Name | 2–20 символів |
| Description | 0-100 символів |
| Type | 0–4: Rectangle, Circle, Triangle, Line, Text |
| Colour | 0–10: White, Pink, Red, Orange, Yellow, Lime, Green, Cyan, Blue, Purple, Black |
| X, Y | від 0 до W − 1, від 0 до H − 1 |
| Width, Height | від 1 до W − X, від 1 до H − Y |
| Symbol | рівно один символ |
| Price | невід'ємне число |

### Пошук і видалення об'єкта
Поля нумеруються таким чином:
- 1 — Name;
- 2 — Description;
- 3 — Type;
- 4 — X;
- 5 — Y;
- 6 — Width;
- 7 — Height;
- 8 — Colour;
- 9 — Visible;
- 10 — Symbol;
- 11 — Price.

#### Пошук
Пошук вимагає збігу за двома обраними полями одночасно, але враховується і той варіант, де користувач може знайти об'єкт лише за одним параметром, обраним двічі. Тоді потрібно лише один раз вписати параметр, а не два рази підряд.

#### Видалення
Видалення можливе за номером у таблиці або за одним полем (Видаляються всі збіги).

### Демонстрація поведінки
Після вибору об'єкта доступне підменю:
- 1 — зміщення;
- 2 — зміна розміру;
- 3 — перемикання видимості;
- 4 — обчислення площі;
- 5 — інформація про модель;
- 0 — назад.

### Демонстрація статичних методів
Після вибору об'єкта доступне підменю:
- 1 — отримати поточне масштабування;
- 2 — змінити поточне масштабування;
- 3 — отримати загальну кількість моделей;
- 0 — назад.

| `Enums.cs` | Перелічення `Colour` і `ShapeType` |

## Версії
Проєкт використовує власну систему версіонування у форматі `MAJOR.MINOR.PATCH` (наприклад, `1.2.3`):

- **MAJOR** — докорінна зміна програми, що свідчить про завершення чергового великого етапу розробки. Сюди відносяться глобальні зміни архітектури або функціоналу.
- **MINOR** — менш значна зміна: перепис частини програми без суттєвих змін у функціоналі або з метою спрощення коду.
- **PATCH** — патчі, що налагоджують роботу окремих функцій, виправляють баги та помилки, виявлені під час використання програми.

### ConsoleGraphicsEditor
Даний продукт - графічний редактор в консолі, який генерує графічні моделі й користувач може взаємодіяти з ним тим чи іншим способом. Створений виключено в навчальних цілях

## Можливості
- створення моделі з властивостями: назва, тип, колір, символ, координати, розміри, видимість, ціна;
- перегляд усіх моделей у вигляді таблиці;
- пошук за двома характеристиками одночасно;
- видалення за номером або за характеристикою;
- демонстрація поведінки моделі: переміщення, зміна розміру й кольору, перемикання видимості, обчислення площі, виведення інформації;
- перевірка введення: некоректні дані запитуються повторно, програма не завершується.

## Запуск

Готової збірки немає: програма запускається з вихідного коду у Visual Studio. Командний рядок не потрібен.

1. Завантажити проєкт: на сторінці репозиторію GitHub натиснути **Code → Download ZIP** і розпакувати архів (або клонувати репозиторій через **Git → Clone Repository** у Visual Studio).
2. Відкрити у Visual Studio файл рішення з розширенням `.sln`.
3. Натиснути **Ctrl+F5** (Start Without Debugging). Відкриється консольне вікно програми.
Для роботи потрібна Visual Studio з робочим навантаженням **.NET desktop development**. Якщо середовище запропонує встановити відсутній компонент .NET, слід погодитися.

## Використання

На старті задаються максимальна кількість об'єктів та розміри полотна (усі значення в межах 1–1000). Головне меню: 1 — додати, 2 — переглянути, 3 — знайти, 4 — продемонструвати поведінку, 5 — видалити, 0 — вийти.

Обмеження при створенні об'єкта (W, H — ширина й висота полотна):

Поле	Допустиме значення
Name	2–20 символів
Type	0–4: Rectangle, Circle, Triangle, Line, Text
Colour	0–10: White, Pink, Red, Orange, Yellow, Lime, Green, Cyan, Blue, Purple, Black
Symbol	рівно один символ
X, Y	від 0 до W − 1, від 0 до H − 1
Width, Height	від 1 до W − X, від 1 до H − Y
Visible	0 — false, 1 — true
Price	невід'ємне число

### Пошук і видалення
Поля нумеруються: 1 — Name, 2 — Type, 3 — X, 4 — Y, 5 — Width, 6 — Height, 7 — Colour, 8 — Visible, 9 — Symbol, 10 — Price. Пошук вимагає збігу за двома обраними полями одночасно. Видалення можливе за номером у таблиці або за одним полем (видаляються всі збіги).

### Демонстрація поведінки
Після вибору об'єкта доступне підменю: 1 — зміщення, 2 — зміна розміру, 3 — зміна кольору, 4 — перемикання видимості, 5 — обчислення площі, 6 — інформація про модель, 0 — назад.

## Структура проєкту

|------|-------------|
| `Program.cs` | Точка входу, меню, колекція об'єктів, пошук, видалення, таблиця, безпечне введення |

## Версії
Проєкт використовує власну систему версіонування у форматі `MAJOR.MINOR.PATCH` (наприклад, `1.2.3`):

- **MAJOR** — докорінна зміна програми, що свідчить про завершення чергового великого етапу розробки. Сюди відносяться глобальні зміни архітектури або функціоналу.
- **MINOR** — менш значна зміна: перепис частини програми без суттєвих змін у функціоналі або з метою спрощення коду.
- **PATCH** — патчі, що налагоджують роботу окремих функцій, виправляють баги та помилки, виявлені під час використання програми.

## Відомі обмеження
 
- Програма керує властивостями моделей, але не відмальовує їх на полотні.
- Поле `Visible` у пошуку й видаленні вводиться як `true`/`false`, а при створенні — як `0`/`1`.
